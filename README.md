# Kasper | Template Two

Eine moderne one-page Landingpage, die das bekannte Kasper-Template inspiriert. Das Projekt besteht aus einer responsiven Startseite mit Hero-Bereich, Services, Design-Section, Portfolio, Video, Pricing und Contact-Abschnitten.

## Überblick

Dieses Projekt ist eine statische HTML/CSS-Website ohne Frontend-Framework oder Build-Prozess. Die Gestaltung basiert auf einer klaren, modernen Layout-Struktur und verwendet Google Fonts sowie Font Awesome Icons.

## Technologien

- HTML5
- CSS3
- Font Awesome
- Google Fonts

## Projektstruktur

```text
.
├── index.html

│   ├── all.min.css
│   ├── kasper.css
│   └── normalize.css

```

## Funktionen

- Responsive Navigation mit Burger-Menü
- Hero-Banner mit Overlay und Call-to-Action
- Services-Sektion
- Design-/Feature-Bereich
- Portfolio-Galerie
- Video-Abschnitt
- Pricing- und Kontaktbereiche
- Mobile-optimierte Darstellung

## Lokales Ausführen

Da es sich um eine statische Webseite handelt, musst du keine Installation durchführen.

### Option 1: Direkt im Browser öffnen

1. Öffne die Datei `index.html` in einem Browser.

### Option 2: Lokaler Webserver

Im Projektordner ausführen:

```bash
python3 -m http.server 8000
```

Danach in den Browser öffnen:

```text
http://localhost:8000
```

## Wichtige Dateien

- `index.html` – Hauptstruktur der Seite
- `css/kasper.css` – Haupt-Styling der Vorlage
- `css/normalize.css` – CSS-Reset für konsistente Darstellung
- `css/all.min.css` – Font Awesome Styles
- `image/` – Grafiken und Medien
